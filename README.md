# Data Structures: Singly Linked List in C

A core Data Structures & Algorithms (DSA) implementation demonstrating dynamic memory allocation, node creation, traversal, insertion, searching, and deletion in C.

## Concepts Covered
* **Dynamic Node Allocation**: Using `malloc` and `free` for heap-based memory management.
* **Pointers & References**: Traversing pointer chains (`next`) to connect sequential records.
* **CRUD Operations**: Inserting elements, searching node values, and unlinking nodes safely.

## How to Compile & Run
```bash
gcc main.c -o linked_list
./linked_list
